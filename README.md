# AeroTrace

Аналитический дашборд для мониторинга экологических показателей.

Веб-приложение для визуализации данных с датчиков экологического мониторинга
(температура, влажность, CO₂, PM2.5): интерактивные графики и карта станций,
оповещения при превышении нормативных значений, экспорт отчётов, исторические тренды.

Проект выполняется в рамках производственной практики по модулю ПМ.08
«Разработка дизайна веб-приложений» (специальность 09.02.07, группа И-3Б).
